- removido botão de pxg tools já que o projeto foi descontinuado pelo criador
- removida tag BETA do GridView
- Selkies está em manutenção
- adicionada informação em `machine setup` sobre como funciona o recreate e quais casos a máquina desliga
- adicionada informação pra deixar bem claro que o nick do personagem do painel precisa ser o mesmo do char que vai usar o bot no game na aba de criação de personagens
- melhoradas algumas traduções
- adicionadas novas traduções
- adicionado balão que recomenda usar !hotkeys pra saber todas hotkeys
- adicionada mensagem ao salvar configs com sucesso lembrando você de dar `ALT + I` pra carregar suas alterações do bot in-game
- ao criar uma maquina pela primeira vez, agora dispara o recreate automaticamente (momento da ativação da licença)
- adicionada DICA in-game pra não usar CapsLook pra digitar senhas
::

::en
- Removed the PXG Tools button since the project has been discontinued by its creator
- Removed the BETA tag from GridView
- Selkies is currently under maintenance
- Added information in `machine setup` explaining how recreate works and in which cases the machine shuts down
- Added clear information stating that the character nickname in the panel must be the same as the character that will use the bot in-game, in the character creation tab
- Improved some translations
- Added new translations
- Added a tooltip recommending the use of !hotkeys to see all available hotkeys
- Added a success message when saving configs, reminding you to press `ALT + I` to load your bot changes in-game
- When creating a machine for the first time, recreate is now triggered automatically (at the moment of license activation)
- Added an in-game TIP advising not to use Caps Lock when typing passwords
::
