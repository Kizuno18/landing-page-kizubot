::pt
- **itemUsage** saiu do beta e evoluiu para **Actions** que entrou no beta.
- agora é possível Programar o bot pra ficar ativado até determinado horário e depois deslogar sozinho após determinado horário ou horário programado
- agora é possível Programar tempo pra deslogar, deslogar quando aparecer player
- agora é possível Programar pra Finalizar lure e dar reconect e retomar hunt dps de x tempo que eu definir
- agora é possível Programar pra Identificar server save e 3 min antes finalizar o lure bater rvv e deslogar
- agora é possível Programar Resposta automática para players
- agora ignoredNames em alarmes ignora corretamente alarmes de mega se voce digitar por ex "mega lopunny"
::

::en
- now ignoredNames in alarms correctly ignores mega alarms if you type for example "mega lopunny"
- **itemUsage** has left beta and evolved into **Actions**, which entered beta
- it’s now possible to Schedule the bot to stay active until a specific time and then log out automatically after that time or at a programmed time
- it’s now possible to Schedule a timer to log out, log out when a player appears
- it’s now possible to Schedule to Finish lure and reconnect, then resume hunt after X time that I define
- it’s now possible to Schedule to Detect server save and 3 minutes before finish the lure, use rvv, and log out
- it’s now possible to Schedule Automatic responses to players
- now ignoredNames in alarms correctly ignores mega alarms if you type for example "mega lopunny"
::
