- removidos botoes do HUD de reload config e stack money
- trocada a cor do HUD
- adicionado mais espaçamento às linhas do HUD
- adicionadas 2 novas informações ao HUD
- 1. nome da waypoint carregada
- 2. quantidade de passos que tem a waypoint
- agora se você deixar o **alarme** de **dropRare** ativado você receberá uma surpresa a cada 20min no whatsapp 🤩🤫
- melhorado o uso de revive
- agora quando a **IA** não conseguir carregar suas **waypoints** ela vai tentar novamente.
- corrigido um bug eventual no critical revive
- agora quando a **IA** não conseguir carregar sua **config** ela vai tentar novamente caso tenha ocorrido problema de conexão com o banco de dados
- agora a **IA** sabe reconhecer quando você está na nightmare
- correção em bug eventual que fazia com que a **IA** pensasse que estava com o pokemon sumonado, mas não estava
- melhorias em casos especificos onde o **PXG** reiniciava pois a **IA** usava muito processador

::en
- removed HUD buttons for reload config and stack money
- changed HUD color
- added more spacing between HUD lines
- added 2 new pieces of information to the HUD:
-  1. loaded **waypoint** name
-  2. number of steps in the **waypoint**
- now, if you leave the **dropRare** **alarm** activated, you'll receive a surprise on WhatsApp every 20 minutes 🤩🤫
- improved revive usage
- now, when the **AI** fails to load your **waypoints**, it will try again.
- fixed an occasional bug in critical revive
- now, when the **AI** fails to load your **config**, it will attempt again if there was a connection problem with the database
- the **AI** now recognizes when you are in nightmare
- fixed an occasional bug where the **AI** thought a Pokémon was summoned but it wasn't
- improvements in specific cases where **PXG** would restart due to the **AI** using too much CPU
::
