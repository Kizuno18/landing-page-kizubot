::pt
- resolvido minMonstersToOrder na aba combat que não funcionava ainda pra orderOnSelf
- adicionado forceComboAtHealth na aba **combat** pra você controlar melhor com qual vida começa a combar
- corrigido problema de vários **FOODS** que a **IA** não detectava corretamente
- corrigido problema de diversas **BALLS** que a **IA** não detectava corretamente
- agora forceComboOnDespawnWarning foi renomeado pra waitLureOnDespawnWarning
- espera-se que waitLureOnDespawnWarning apenas pare de caminhar e aguarde o lure quando pokémons estiverem com ! de quase despawnando - _se houver bugs, reportem._
- corrigido "CD Delay Before Revive" que não funcionava para criaturas extraordinárias
::

::en
- fixed minMonstersToOrder in the combat tab that still didn’t work for orderOnSelf
- added forceComboAtHealth in the **combat** tab so you can better control at which HP it starts comboing
- fixed issue with several **FOODS** that the **AI** didn’t detect correctly
- fixed issue with several **BALLS** that the **AI** didn’t detect correctly
- renamed forceComboOnDespawnWarning to waitLureOnDespawnWarning
- waitLureOnDespawnWarning is expected to just stop walking and wait for the lure when pokémons are about to despawn with ! – _if there are bugs, please report._
- fixed "CD Delay Before Revive" which didn’t work for extraordinary creatures
::
