- agora é possivel ver varios vnc rodando de uma vez (caso vc tenha mais de uma licença na aba GridView/Panel
- melhorado componente de chat e ações in-game da aba interaction em egine
- corrigidos varios problemas com tirar e colocar pokemon ou lurar sem poke no chão
- adicionado alarmes no dashboard (com som)
- adicionado historico de todos chats do seu personagem no seu dashboard
- melhorada validação de loot pra evitar perder loot sem coletar
- agora é possivel acessar a VNC através do painel - GridView (ainda não é tão fluido quanto REAL VNC)
- otimizada visão de mobile pra varias abas dentro do dashboard
- adicionados botões pra controlar o recreate de dentro do gridView / Panel no dashboard
- adicionada opção pra minizar o vnc no gridview sem fechar a conexão
- adicionada multi vnc support (pra poder ver varias vnc de uma vez no gridview)
- corrigido geração de qrcode pra Sistema do WhatsApp no painel alarms
- otimizações gerais no dashboard

::en
- It is now possible to keep the bot as a mini-player (picture-in-picture) in the dashboard under the GridView/Panel tab.
- A sound alarm system has been added (works on any dashboard tab, which must remain open even in the background or on mobile).
- You can now view multiple VNC sessions at once (if you have more than one license) in the GridView/Panel tab.
- Improved the chat component and in-game action features in the Engine → Interaction tab.
- Fixed several issues related to adding/removing Pokémon or using lures without a Pokémon on the ground.
- Added alarms to the dashboard (with sound).
- Added full chat history of your character to your dashboard.
- Improved loot validation to avoid losing loot without collecting it.
- You can now access VNC directly through the panel → GridView (still not as smooth as REAL VNC).
- Optimized mobile view for several tabs inside the dashboard.
- Added buttons to control "recreate" from within the GridView/Panel in the dashboard.
- Added an option to minimize the VNC in GridView without closing the connection.
- Added multi-VNC support (to view several VNC sessions simultaneously in GridView).
- Fixed QR code generation for the WhatsApp System in the Alarms panel.
- General dashboard optimizations.
::
