::pt
- agora é possível atribuir uma **hotkey** pra qualquer action (isso permite fazer hotkeys de combo, revive etc)
- autoStackMoney previamente usado através da hotkey **ALT+J** pra stackar dinheiro do market, agora foi movido pra aba **Actions** e tem seu preset em **Quick Actions**
- corrigido problema no sistema de reconnect
- limpeza de código antigo pra nova geração da KizuBot **AI**
::

::en
- It's now possible to assign a **hotkey** to any action (this allows for combo, revive, and other custom hotkeys)
- The previous **ALT+J** hotkey for autoStackMoney (used to stack market money) has been moved to the **Actions** tab and now has a preset under **Quick Actions**
- Fixed an issue with the reconnect system
- Cleaned up legacy code for the new generation of KizuBot **AI**
::
