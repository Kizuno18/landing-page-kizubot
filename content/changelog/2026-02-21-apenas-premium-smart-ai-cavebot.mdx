::en
- Removed cavebot function `avoidLostMultiplier`
- Removed cavebot function `maxWalkAttempts`
- Removed cavebot function `nodeRadius`
- Fixed a small bug in the `walk_to_waypoint` and `set_cavebot_waypoint` action options
- Greatly improved the `cloudFarming` option (formerly VIP1) **premium only**
- Improved loot collection (seems much more human-like)
- Improved **smart AI** humanization system
- Improved anti-lost Pokémon feature
- Simplified **Cavebot** settings
- In the **Cavebot** tab, the `Dash While Luring` option has been added. For more information, check the description
- In the **Cavebot** tab, the Lure `Anti-Lost` process is now clearly detailed
- Improved priorities: now the **AI** prioritizes Loot > Catch > Tall Grass > bush/wood/ore > headbutt, and finally > normal cavebot walk
- Improved safety and anti-detection strategies for **KizuBot**
- Fixed the function that notifies **KizuBot** Developers about bugs (fixes will now happen faster)
- The **AI** can now detect your character's speed and use it intelligently
- The **AI** now considers the `PING` during the cavebot process to calculate compensation
- Improved humanization of _"nodes"_ and now it is **automatic**
- Fixed issues with stairs
- Improved recorder for stairs
- Improved cavebot when dealing with stairs
- Now, if stuck near stairs, the bot will not remain stuck forever. In less than 1 minute, it will recalculate (based on `Wait Time (seconds)` configurable as a sub-option in the alarm -> `CharacterStucked`, and **if disabled** the default will be 20)
- Now, stepping on **Tall Grass** no longer causes the cavebot to "recalculate route"
- Now, when activating `Auto Switch Hunt`, it’s not 100% literal. For example, test_starm_big_2025 would work for _starmie_ but not for _staryu_
- The new slow lure system: if you are MOVING towards creatures, it won't walk as slowly (recognizes what is truly Lost)
- The bot now collects loot in a more logical way. For example, if the waypoints are leading to the left and the corpses are on the right, it will collect from the right side first and then the left, so it is already aligned with the route to continue the cavebot
- Fixed an issue where the cavebot appeared to “try to move” while collecting farming resources
